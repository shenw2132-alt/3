# 花呗还款模拟（PWA）

## 部署到 GitHub Pages
1. 新建 Public 仓库，把本文件夹内的所有文件上传到仓库根目录（index.html 必须在最外层）。
2. Settings → Pages → Source 选 Deploy from a branch，分支 main，目录 / (root)。
3. 访问 https://你的用户名.github.io/仓库名/

## 手机安装
- iPhone：用 Safari 打开 → 分享 → 添加到主屏幕
- 安卓：用 Chrome 打开 → 菜单 → 安装应用

## 更换桌面图标
用你自己的图标图片，按下面的尺寸（PNG，正方形）覆盖同名文件即可：
- icon-512.png     512x512
- icon-192.png     192x192
- apple-touch-icon.png  180x180（iPhone 使用）
图标主体请放在画面中间 80% 范围内，四周留白，避免被圆角裁切。

## 更新版本
修改页面后，把 sw.js 第一行的 huabei-sim-v1 改成 v2、v3……，手机才会拿到新版本。

本应用仅为模拟演示，非真实交易。
